学科视域（第二版）

这里不说我上过什么课。

这里只回答两件事：这些东西为什么值得知道，以及它们究竟是什么。

一份按世界自身的层次重排的通识底稿，十二个板块，约 13 万字。不按任何学科边界或课表分，因为学科是把连续的东西切开、分给不同委员会的结果——而这近十年来多数真正有意思的事，都发生在切口上。

这是什么，不是什么

它不是教材。 教材的目的是让你能在考试中复现；这里的目的是让你不再被骗——包括不被别人骗，也包括不被自己骗。

它也不按学科分。 你会发现「守恒」「平衡」「反馈」「边界」这几个词在每个板块都出现，只是换了外衣。这不是类比，是同一件事在不同层次上的样子。

它能给你的是知识的本来面目，给不了你使用它的能力。 前者可以读，后者必须自己走一遍。这一点总说里写得更不留情面。

给谁看

写给三种人：

  • 已经上过课、却说不清自己学的那门在干什么的人。 知识的位置变了——它从目的变成了材料，但多数人的用法还停在上一个时代。
  • 跨进来的人。 想问另一个领域的问题，需要先知道那个领域的「标准问题」长什么样，否则连切入点都找不到。
  • 准备开始教别人的人。 每一篇的「为什么值得知道」都是可以直接拿走的一段开场。

不要求任何前置基础。一句话是一种承诺：不引用任何课程、教材、章节。 碰到了绕不过去的术语，就地解释。

怎么读

只想花三分钟

读 00-总说.md 的第一节。它用六个「不知道会怎样」的具体场面回答了一个问题——如果这些内容缺一块，我会在什么地方、以什么方式吃亏。读完你就知道要不要继续。

只想拿走一件东西

读 边界清单.md。它把十二个板块里散落各处的「什么时候不成立」抽成了一张可以当工具查的表格。如果这个文件只能留下一页，留这一页。

路线 A：从吃过的亏开始（推荐给第一次来的人）

正典顺序是「由深到浅排世界」，所以第一篇恰恰是最抽象的——不建议从它开始。这条路线从最具体的日常损失切入，把难啃的留到你有兴趣之后：

顺序 板块 从什么亏开始
1 如何在不确定中判断 被平均数、显著性与幸存者偏差骗过
2 物质如何转化 以为「加大剂量」总能解决问题
3 细胞是什么 以为「多喝水总是好的」「消炎药能治感冒」
4 人如何一起做事 见过一群好人把事做黄，不知道为什么
5 多样性从哪来 用「为了……」解释一切现状

之后再回头攻 01 如何描述世界，或者干脆顺着路线 B 正读一遍。

路线 B：顺着世界的层次往下（正典顺序）

这是作者排的顺序，按「世界有多深」，不是由易到难。建议按这个顺序读第二批。

# 板块 一句话
01 如何描述世界 把「关系」从具体事物里抽出来——这是全部定量科学的起点
02 世界由什么构成 原子、化学键、分子形状：物质为什么这样组合
03 物质如何转化 平衡决定「能不能」，速率决定「多快」——两件必须分开的事
04 生命的分子 四类大分子与酶：生命用的那套零件
05 能量如何流动 生命靠「耦合」驱动，而不是靠提高效率
06 信息如何传递 复制、转录、翻译、调控：一套有校对机制的信息系统
07 细胞是什么 用膜隔出空间，让化学反应有秩序地发生
08 生物体如何运作 分工、调控、以及「看起来像设计却没有设计者」
09 多样性从哪来 变异 + 选择 + 不可重复的历史
10 如何把发现变成产品 放大、传递、取舍：从试管到万吨
11 如何在不确定中判断 从有限的、带噪声的样本里得到可靠结论
12 人如何一起做事 素不相识的人如何形成稳定秩序

其中 02–03 是全部自然科学的底座，04–06 是生命的三个层次（分子、能量、信息，互相咬合，缺一讲不通），07–08 是把分子组织起来，09 是关于时间，10–12 是关于「用」。

每一篇的固定体例

十二篇严格照同一个模子写，这条一致性是这个项目最值钱的东西：

位置 回答什么 写法上的硬性要求
一句话 整篇的核心 20 字以内，不许用术语糊过去
一、为什么值得知道 不知道会怎样被骗 只给具体情形，不给「很重要」
为什么缺的人不自觉 知识的缺口为什么不痛 必须说清那个「用错还没感觉」的机制
承诺句 读完多出哪一种判断力 「你会换一种看法，而不是变聪明」
二、它究竟是什么 知识的本来面目 平白的话，不引用任何教材章节
边界 这条结论在什么条件下失效 每一小节都必须有，没有例外
收束 只留一个想法 回扣开头那句话

读第二节时建议随时问一句「这个结论在什么条件下不成立」。每条知识都有边界，而边界恰恰是它最有用的部分。

关于确定的程度

这份东西刻意区分了三种说法的强度，阅读时请注意分辨：

  • 有数据或定理支撑的结论——通常带具体年份、人名、次数。
  • 量级估计——明写「量级估计」。它用来快速排除荒谬方案，不是精确承诺，也不替安全、法规、不可逆的承诺背书。
  • 有争议的说法——明写「有争议」。比如韦伯对新教伦理与资本主义精神的解释、150 人这个社交上限的具体数字、癌细胞需要几个环节同时失守。这些地方宁可把争议留着，也不给你一个整齐的错答案。

遇到超过 100 的数字，默认它是量级而不是精度。

怎么参与

这个项目目前是一个人的稿子，但它是按可以改的形式组织的：

  • 发现某处的边界漏了——最值得提的一种。每个板块末尾都有前后导航和建议动作。
  • 发现某个数字或年份过时了——直接改，顺手附一句出处。正文里的说法一般不依赖具体数字的精度，所以这类改动风险很低。
  • 发现某个「为什么值得知道」的例子不够贴——欢迎整例替换。这一节唯一的标准就是「读者会不会觉得这说的是我」。

改的时候尽量只动一处，不要把整段重写一遍——12 篇能保持一个语气，是因为每一处改动都足够小。

网页版

本仓库的 Markdown 源会自动渲染成一套静态网站，输出在 docs/ 目录，可直接作为 GitHub Pages 发布（仓库设置 → Pages → 来源选 main 分支的 /docs 文件夹）。

  • 在线浏览：首页、总说、十二个板块与边界清单各为一页，带侧边导航与上下翻页。
  • 本地预览：python3 -m http.server -d docs 后打开 http://127.0.0.1:8000。
  • 重新生成：改完任意 .md 后运行 python3 build_site.py 即可（依赖 pip install markdown）。

源 Markdown 仍是唯一真相，网页只是它的另一种呈现。
