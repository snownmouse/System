边界清单

这份文档最值钱的地方不在结论，而在每条结论后面跟着的那句"什么时候不成立"。它们散落在十二个板块里，这里把它们聚到一起，方便当工具查。

读法：先看"什么时候成立"锁定这条知识的地盘，再看"什么时候会断"避开常见误读，最后看"换成什么 / 该问什么"——作者给出的替代工具或必须补查的前提。

提醒一句：每条知识的边界恰恰是它最有用的部分。模型必然丢信息，公理只能选、不能证，结论永远挂着一串前提。能说出"这依赖什么"，比背下结论更接近这份文档想给你的东西。

01 如何描述世界

一句话：把"关系"从具体事物里抽出来，同一套推理能跨对象复用。

什么时候成立 什么时候会断 换成什么 / 该问什么
同构只在"相对于哪些运算"下成立 问题里同时需要乘法和加法（如解二次方程） 检查两种运算是否都在结构里
抽象能把推理用到任意对象 抽得太干净会丢掉量纲和尺度 从结构外补回量纲、范围、尺度
线性逼近在平衡点附近好用 小范围多远才失效无通用标准 先问"离展开点多远"
导数 / 积分描述"变"与"累积" 曲线有尖点、分形，导数不存在 退回差商或弱导数
无限和可以收敛到确定值 收敛依赖你用的度量，还依赖定义 先问"按什么距离衡量接近"
可判定问题有算法 "不可判定"指无通用算法，不指单个问题没答案 改问：哪类输入、什么条件下可解
形式推演可靠 形式严格会掩盖前提，前提不写在推导里 反问"这依赖什么"并去查那条

02 世界由什么构成

一句话：物质的性质写在电子怎么排、原子怎么连、连成什么形状上。

什么时候成立 什么时候会断 换成什么 / 该问什么
周期律由电子填充顺序决定 填充顺序是近似规则，铬铜有例外 重元素改用更细的能级模型
电负性差判断电荷往哪偏 0.4/1.7 门槛是粗略刻度非自然分界线 只当快速估计，不当真规则
离子 / 共价 / 金属键分三档 真实键没有纯版本，氯化钠只约七成离子性 用"电子分布铺满分子"的图像
排斥模型定分子形状 对过渡金属配合物失灵，中央原子越大越不准 改用 d 电子参与的规则
氢键、疏水作用托起宏观结构 单个弱作用低于热噪声，只描述统计偏好 改问"构象占多大比例、待多久"
相似相溶 极性不是二元的；某些体系反常溶解 / 盐析 用连续极性指标，而非能溶/不能溶
这套解释成立于分子尺度、常温常压 成键瞬间要量子力学，亿万个分子要统计描述 弱作用必换统计；纳米尺度性质会变
结构式描述分子 平面式子丢三维手性、构象、电子分布 记住"结构式是索引，不是实物"

03 物质如何转化

一句话："能不能"由自由能决定，"多快"由势垒决定，两者没有桥。

什么时候成立 什么时候会断 换成什么 / 该问什么
自由能判方向、平衡常数判终点 两式只在定温定压下成立，K 依赖标准态 改条件必须重算活度
平衡有确定位置 平衡只在封闭系统有意义；活细胞是稳态 开放系统问"流入=流出"
平衡是反应停了 它两个方向同速跑，是动态平衡 别把"宏观不变"当"微观静止"
速率方程可写出 速率必须实测，不能从总反应式读出 观察对哪物不敏感即知慢步骤
催化剂让反应更快 它不改变终点，会中毒、失活、改实际路径 问"它还能不能一直用下去"
用浓度代活度算平衡 只在稀溶液成立，浓溶液偏得离谱 引入活度系数
热力学说"能不能" 可行而实际不动是最常见误判 热力学给许可，不给出承诺

04 生命的分子

一句话：生命只用四类零件，各自岗位是被化学性格逼出来的。

什么时候成立 什么时候会断 换成什么 / 该问什么
结构决定功能 只在该结构在某条件下会变时成立 先问"它靠什么结构、何时会变"
序列决定折叠决定功能 绝大多数单点替换无可见效果，致命是特例 判断"改了形状的哪一部分"
酶降势垒、不改平衡 专一性非绝对，会打到错酶成副作用 多齿 / 选择性从结合过渡态更强
米氏方程描述饱和 Km≠亲和力（有条件）；别构酶是 S 形 体内多在半饱和区，调控才起作用
体外机制都成立 试管里纯蛋白 ≠ 体内（拥挤、竞争、伴侣） "体外有效"不能直接推"体内有效"
找到基因 / 蛋白即解释 关联位置≠功能；冗余让敲除无表型 扰动→回补→体外重构三步钉死
四类零件分工清晰 蛋白质非唯一催化剂（RNA 也行）；DNA 非唯一信息载体 分工是后来分开的，非天生

05 能量如何流动

一句话：能量从不消失，但一直在变便宜，生命不过在下落路上借水轮。

什么时候成立 什么时候会断 换成什么 / 该问什么
第一定律守总量 它答总量，生活里真问题几乎都问"方向" 先问能不能用，不只问还在不在
第二定律管方向（孤立系统） 只直接适用于孤立系统，生命靠外部供能 看"系统+环境"的总账
ΔG 判自发 它判方向不判速率；标准态值不能直接用 细胞里 ATP 实际值常差近一倍
ΔG=0 是平衡 它正逆同速跑，不是停止 最忙的常是看起来静止的地方
生命靠耦合拖不利步骤 总账必须为负，转换永远有损耗 酶不改变平衡位置
发酵是无氧时的快路 不能长期维持；产物有毒；低氧也走发酵 它的目标函数常非"最大 ATP"
"生命高效" 强竞争贫瘠环境才逼近极限，非普遍 先弄清这一步是不是限制环节
"负熵"话术 它是定性框架给不出数值，常被当实体卖 问"测什么、单位、前后变化多少"

06 信息如何传递

一句话：生命的信息系统是一套为保真而持续付代价的机制。

什么时候成立 什么时候会断 换成什么 / 该问什么
信息可搬动、内容不损失 "不损失"≠载体无关，载体决定耐久与速度 DNA/RNA/蛋白命运量级不同
碱基配对保证复制特异 特异性非绝对，错配真实发生 正因有残余错误率才必须有校对
配对推出复制转录测序 A-T/G-C 非唯一可能，是选中的化学规则 实验室已有"扩展字母表"
链只能朝一个方向长 环状基因组没有端粒问题 需要端粒的恰是线性基因组
简并缓冲突变 对平均成立、对具体位置不成立 两种氨基酸各只有一个码字
中心法则 准确版是"序列不能从蛋白回核酸" 构象→构象、RNA→RNA 是补充
保真度越高越好 完全不突变就没有进化材料 突变率本身是被选择的对象
找到基因＝解释功能 关联≠机制；跨代表观遗传被严重夸大 标签方便交流但非机制已知
"随机"变异 指方向不指速率；无方向≠无偏 热点、上下文让素材库有结构

07 细胞是什么

一句话：细胞是用膜隔出的空间，靠持续耗能维持里外不一样。

什么时候成立 什么时候会断 换成什么 / 该问什么
脂双层自组装成膜 它不保证大小一致、也不保证装什么 大小与内容靠通道、泵另管
膜是有选择性的门 选择性来自搬运装置，不是筛子 逆梯度必须耗能，无例外
区室化让矛盾反应并行 细菌无膜细胞器照样有秩序 普遍规律是"限制在小范围"
蛋白靠信号肽去该去处 信号必要不充分，有的靠搭便车 "主要写在序列里"，不是全部
信号级联放大微弱信号 放大同样放大噪声，须有阈值 灵敏与误报是必须同处理的矛盾
检查点拦住错误 它核对内部标准，非后果；坏≠必癌变 失控常需多个环节同时失守
"细胞是工厂"隐喻 无总设计师、无图纸中心、效率非目标 改说"被膜围起、持续耗能的空间秩序"
体外结论直接外推人体 培养皿细胞与体内差很大 问"在哪种细胞、什么条件下"

08 生物体如何运作

一句话：生物体不是被设计的机器，而是受约束、带反馈、带历史的修补过程。

什么时候成立 什么时候会断 换成什么 / 该问什么
分工—整合框架 对单细胞无意义；对蚁群只是类比 从细胞到个体不能随便跨层次
稳态是自动往回调 波动常正常；参考值是历史产物非最优 还有大量"前馈"依赖预测
反馈维持一个量 增益过大发散、延迟来回摆、参考值被改 响应更"积极"≠更好
"看起来像被设计" 无设计者；"为了…"要可检验才成解释 给不出可检验后果只是想得通
适应＝最优 是历史包袱、约束权衡下的"够用" 问"在何时何地被留下来"
免疫区分自己/非己 两层深度耦合；自身免疫/过敏是固有代价 "像军队"隐喻暗示不存在的指挥
小鼠等模型结论搬人 生活史/器官绑定的结论须逐项重验 按体重标度换算本身有争议
过敏=免疫力太强 错在"像不像敌人"的判断，非火力 增强误判系统只会让误判更贵

09 多样性从哪来

一句话：变异是盲的，选择是不盲的，历史不许重来——三者相乘。

什么时候成立 什么时候会断 换成什么 / 该问什么
突变随机 "随机"指方向非速率；位点不均、有热点 细菌应激可上调错误频率
选择让结果像有目的 小种群里漂变压过选择（看 |N·s| 的大小） 有效种群 Ne 常远少于个体数
保真度越高越好 太高丢适应材料，太低丢信息 生命待在两代价相抵的带里
选择在某层次发生 基因/个体/群体/物种，争论未结束 "能解释"≠"解释对了"
演化＝进步/有终点 无方向无终点；现存只证明还没被淘汰 环境变常快过适应速度
每个性状都是适应 漂变、历史约束、副作用也常见 "为了…"须多谱系对照才可信
隔离+时间→分化 隔离非黑即白；无地理隔离也能分化有争议 分化不总朝"更分开"走
演化必然缓慢 世代数与选择压强足够强就很快 压松（庇护所）则变慢或回退

10 如何把发现变成产品

一句话：从玻璃器皿到每天几吨，隔着守恒、传递与取舍三套硬约束。

什么时候成立 什么时候会断 换成什么 / 该问什么
衡算：输入−输出+生成−消耗=积累 它管总量，不告速率与可行性 账平是必要非充分条件
量级估算快速排荒谬方案 安全/法规/不可逆承诺不作数 幂次错（线当方）结论会反
流量=推动力÷阻力 本质线性；湍流阻随流量平方变 耦合时只局部、瞬时成立
平衡定上限、传递定代价 平衡是热力学，与速率无关 平衡太差须改条件非改设备
放大按几何相似 面积∝L²、体积∝L³，无量纲准则不可全保 挑最不能牺牲的准则保，其余认了
保溶氧与保剪切 几何相似下两者数学互斥 先找真正瓶颈再决定牺牲谁
"最优"可言 无目标函数就没有最优；权重是人拍的 多目标是帕累托前沿，选是价值判断
实验室成功=能生产 小试参数不能外推；靠壁面的现象搬走就失效 问"做不快/不纯/不稳/不划算/出事"

11 如何在不确定中判断

一句话：世界只给你带噪声的样本，能不能判断取决于你问得出样本来路。

什么时候成立 什么时候会断 换成什么 / 该问什么
钟形曲线到处是 只当粗尺子；重尾/乘性/相关/有边界会失效 财富、收入是重尾，平均数无意义
标准误=σ/√n 收缩误差 须独立抽样；只度量随机误差不度量偏差 有效样本量常远小于名义
样本越多越准 系统误差不被更多样本修好→精确地错 问"误差方向与抽多少样本有关吗"
95%置信/显著 是流程长期命中率，非单次正确概率 显著≠效应大，问"值多少钱"
不显著=没作用 只说明这次从噪声里分不出 看是否报告了功效（检出概率）
相关推测因果 四种解释数据本身分不清 靠随机化/对照/工具变量/自然实验
合并数据看方向 分组后方向可能全反（辛普森） 问"有没有按重要变量分层"
重复=可靠 发表偏差、小样本、自由度让重复率偏低 看方向是否被多团队多设计确认
统计能回答一切 只管随机误差；不适用单次不可重复事件 这类问题只能机制/历史判断，承认无区间

12 人如何一起做事

一句话：素不相识的人能形成秩序，靠几条各自有条件、各自会断的机制。

什么时候成立 什么时候会断 换成什么 / 该问什么
集体困境靠机制化解 困境成立取决于条件非品格 重复、可识、有退出则自觉也能成
强制见效快 谁来看管看管者（无穷倒退）；需本地知识时最差 链条终点只能靠强制以外的东西
市场配置资源 无法定价之物（外部性）、信息严重不对称 前提：产权、契约、货币、竞争、退出
规范信任最省成本 熟人半径外、一次性交往完全失效 流动拆毁它；声誉可被刷
制度买来可预期 僵化、执行成本超收益、被利益方俘获 对全新类型问题反应最慢
认同最持久 可被操纵；跨国认同在压力下先让路 解决"愿不愿"，解决不了"能不能"
技术扩大协作上限 只决定上限不决定用途；也放大谣言监控 技术不会自动带来秩序
多条机制并行 最易断的是两机制之间的接缝（都以为对方管） 先找最薄一环与重叠空区
信息全公开 透明不匹配调整速度时，透明是放大器 反馈延迟则系统震荡而非稳定

跨板块反复出现的边界

这些话在多个板块里以不同外衣出现，是这份文档真正的骨架：

  1. 模型必然丢信息。 地图不是地形，公式不是现象；被放弃的东西不在结果里留痕迹（01、02、04、10）。
  2. 公理 / 前提只能选、不能证。 结论永远是条件句，"这依赖什么"必须反问；形式严格反而掩盖前提（01、03、05、11）。
  3. 守恒与平衡都有适用尺度。 只在封闭 / 孤立 / 定温定压 / 稀溶液下成立，活系统是稳态、靠偏离活着（02、03、05、10）。
  4. 量级估计不是精确承诺。 它用来快速排除荒谬方案，不替安全、法规、不可逆承诺背书（01、02、03、10）。
  5. "能不能"与"多快"是两件事，没有桥。 热力学给许可，动力学给时间，混在一起努力方向整体反（03、05、10）。
  6. 局部信息与全局后果会错位。 样本有偏、1/√n 只量随机误差、系统误差越信越错（06、11）；两机制接缝最易断（12）。
  7. 尺度一变，性质就变。 几何幂次让放大难，纳米尺度改性质，超出熟人半径规范失效（07、10、12）。
  8. 统计上的偏好不是必然。 单个弱作用低于热噪声、单个事件不可预测，描述的是分布而非个体（02、04、11）。
  9. 恢复力来自冗余而非效率。 生命留冗余、组织靠并联备份；"够用"非"最优"，砍冗余常适得其反（04、07、08）。
  10. "看起来像被设计"无设计者。 配合精密来自累积与约束，适应是历史产物、非最优、非终点（08、09）。
  11. 时间尺度不同，结论会翻。 反馈延迟致震荡，演化快慢看世代数，参考值是历史选的（08、09、12）。
  12. 接口 / 接缝最易漏。 学科把整条链切开、无人认领；重叠区看似双保险实则最空（10、12）。
